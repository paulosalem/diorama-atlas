# Design decisions behind the quality standard

This is a distilled record of the project's design conversations, not a new
visual review. It explains why the current [quality standard](../diorama-standard.md)
is more demanding than "a furnished room with textures."

| Conversation decision                                             | Consequence for future work                                                                                          |
| ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| The Marrakech treatment must **always** carry forward             | Deep detail, connected passages and atmosphere are the starting standard for every family and generated pathway      |
| Use real photographs before implementing the outdoor collection   | Inspect spatial, constructional and object references; preserve actual attribution                                   |
| Represent anonymous similar places rather than specific landmarks | Design original regional settings; do not copy a recognizable square and promise fidelity                            |
| Add an authored touch of atmosphere, beauty and charm             | References inform a composition rather than dictating a sterile replica                                              |
| It must look **and feel** real                                    | Regional atmosphere and the sensory relationships between objects matter as much as geometry                         |
| Work through the smallest geometric and texture details           | Test close views; do not let a good arrival image hide crude joinery, containers or printed props                    |
| "A little mess helps"                                             | Suggest specific ordinary use rather than scatter arbitrary clutter                                                  |
| Imperfections and patina are essential                            | Place cracks, chips, peeling, dirt and use marks selectively, with physical causes                                   |
| Cared-for wood and stone still vary                               | Natural material variation is not the same as neglect; maintenance does not imply uniformity                         |
| Long floors and other textures looked too repetitive              | Break mechanical repetition without breaking construction, joints or intentional pattern                             |
| Water and reflections remained too regular                        | Use coherent irregular flow and motivated disturbance, not synchronized decorative waves                             |
| Covers, jar labels and print need real imagery                    | Give visible print actual content, with physical paper and conforming labels                                         |
| The _Field Notes_ cover was praised as elegant and tasteful       | Match its level of care and integration, not its exact subject or style everywhere                                   |
| Prefer suitable downloadable assets when available                | Reuse licensed imagery and scans before commissioning unnecessary generation                                         |
| Add a consolidated About box for credits                          | Keep sources, licenses, processing and generated-asset provenance accessible                                         |
| Reinspect each new outdoor scene three additional times           | Each requested pass is a complete defect search with corrections, not a repeated approval or a single-category check |
| Narration should explain cultural value in a serious voice        | Provide short bilingual arrival and focused-view passages with matching visible text                                 |
| Language applies to the whole interface                           | en-US and pt-BR must cover controls, errors and explanatory text as well as speech                                   |
| One audio owner, saved choices, no overlapping players            | Reuse the shared lifecycle; respect hiding, mute, tab handover and browser restrictions                              |

The source conversations distinguished an ambitious photographic target from
the achieved rendering. Earlier outdoor photographic-read reviews failed; those
results are preserved in the [outdoor collection record](../outdoor-collection.md).
Functional improvements and later captures must not retroactively turn those
failures into passes.

This record does not authorize paid generation, repository publication or
destructive cleanup in a later task. Those remain explicit decisions for the
work being undertaken.
